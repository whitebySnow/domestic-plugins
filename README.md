# Domestic Email Plugins

MCP plugin collection for Chinese domestic email service providers.

## Included Plugins

### China Email Plugin

MCP plugin supporting major Chinese email services:
- QQ Mail
- NetEase Mail (163.com, 126.com)
- 139 Mail
- Aliyun Mail
- Tencent Enterprise Mail

**Documentation**: [plugins/china-email/README.md](plugins/china-email/README.md)
